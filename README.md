# رفيق المراجعة

تطبيق أندرويد لمراجعة حفظ القرآن الكريم — **وقفٌ لله تعالى**، بلا إعلانات ولا جمع بيانات، ويعمل دون إنترنت.

الروايات: حفص عن عاصم، وورش عن نافع من طريق الأزرق (طريق الأصبهاني قيد البحث عن نص موثوق). الواجهة بالعربية والفرنسية والإنجليزية، بمظهر نهاري هادئ أو ليلي.

## فكرة المراجعة

- **الورد اليومي**: صفحات متتالية من محفوظك تبدأ من حيث توقفت، فتكتمل ختمة مراجعة كل (المحفوظ ÷ الورد) يومًا.
- **التثبيت**: الصفحة التي تقيّمها «ضعيفة» تعود في اليوم التالي زيادةً على الورد حتى تثبت.
- **وضع التسميع**: تُخفى الآيات إلا أول كلمتين، وتكشفها آية آية.
- **مواضع الأخطاء**: تسجّل الآية التي أخطأت فيها لتعود إليها.
- تذكير يومي، ونسخ احتياطي واستعادة.

## التقنية

React + Vite، وCapacitor لبناء تطبيق أندرويد. البناء يتم تلقائيًا على GitHub Actions عند كل رفع إلى `main`، ويُنشر ملف APK في صفحة Releases.

| الملف | الوظيفة |
|---|---|
| `src/schedule.js` | منطق الورد والختمة والتثبيت |
| `src/screens/` | شاشات التطبيق |
| `src/data/<رواية>/` | نص المصحف وحدود الصفحات لكل رواية (مولَّدة بـ `npm run data`) |
| `src/i18n.js` | نصوص الواجهة باللغات الثلاث |
| `src/developer.js` | معلومات المطوّر في شاشة «عن المطوّر» |
| `.github/workflows/android.yml` | بناء APK وتوقيعه ونشره |
| `scripts/make-icons.cjs` | توليد الأيقونات من `resources/icon-fg.svg` |

## مفتاح التوقيع

يُقرأ من GitHub Secrets: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`. لا يُرفع المفتاح إلى المستودع أبدًا.
